# UOL Course Catalogue (Lab Task 02 - RecyclerView)

Mobile Application Development (CS02310) - BS Software Engineering, Section S

An Android (Java) app that shows the courses of the BS-SE programme in a RecyclerView of CardViews.
Tapping a card opens a details screen for that course only, with an "Email Instructor" button.

## Features
- Scenario 1: Course model, CardView item layout, CourseAdapter + ViewHolder, LinearLayoutManager, 8 courses
- Scenario 2: OnItemClickListener, explicit Intent with extras, CourseDetailActivity, ACTION_SENDTO email Intent

## Run
Open the folder in Android Studio, wait for Gradle sync, press Run on an emulator or phone.
